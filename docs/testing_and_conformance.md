# nerve-sdk Testing & Conformance

Verification procedures ensuring SDK types and payloads adhere strictly to gateway and control-plane specifications.

---

## 1. Spec Conformance Test (Ticket 74)

The test file `tests/spec-conformance.test.ts` validates SDK schemas against the canonical OpenAPI specifications generated by the gateway and control-plane:
- Verifies that enum values (`channel`, `priority`, `status`) stay synchronized across Rust, Go, and TypeScript.
- Checks that mandatory properties in TypeScript interfaces cannot drift from OpenAPI contracts.

---

## 2. Running Tests

```bash
# Run Vitest test suite
npm run test

# Run build compilation and typecheck
npm run build
```
